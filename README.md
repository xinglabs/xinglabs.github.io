# XINGLABS personal site

A self-contained, single-page personal laboratory in a Tokyo rain-night visual world.

Open `index.html`, or serve this directory with any static HTTP server. No build, CDN, JavaScript framework, web font, analytics or API is required. GitHub Pages publishes the directory as-is.

- `index.html`: semantic content and navigation. No private projects or personal activity data.
- `styles.css`: responsive layout, visual system and reduced-motion styles.
- `app.js`: bounded canvas rain, pointer light, intersection reveals and a motion toggle. It pauses drawing when the tab is hidden and follows the system reduced-motion preference.
- `assets/tokyo-night.png`: AI-generated atmospheric illustration, supplied for this page.
- `assets/avatar.jpg`: the owner’s existing public GitHub avatar.
- `assets/{mark,eye,city}.svg`: original code-drawn decorative art.

The only external link is the public GitHub profile. All visual assets are local. There is no audio or persistent tracking.
